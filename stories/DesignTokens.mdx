# Design Tokens

Design tokens are the visual design atoms of our design system — specifically, they are named entities that store visual design attributes.

## Colors

### Primary Colors

| Token | Light Mode | Dark Mode | Usage |
|-------|------------|-----------|-------|
| `blue-600` | `#2563eb` | `#3b82f6` | Primary actions, links |
| `blue-500` | `#3b82f6` | `#60a5fa` | Hover states |
| `blue-100` | `#dbeafe` | `#1e3a5f` | Backgrounds |

### Neutral Colors

| Token | Light Mode | Dark Mode | Usage |
|-------|------------|-----------|-------|
| `gray-900` | `#111827` | `#f8fafc` | Primary text |
| `gray-600` | `#4b5563` | `#94a3b8` | Secondary text |
| `gray-100` | `#f3f4f6` | `#1e293b` | Backgrounds |
| `white` | `#ffffff` | `#0f172a` | Card backgrounds |

### Semantic Colors

| Token | Value | Usage |
|-------|-------|-------|
| `success` | `#10b981` | Success messages, confirmations |
| `warning` | `#f59e0b` | Warnings, cautions |

| `info` | `#3b82f6` | Informational messages |
